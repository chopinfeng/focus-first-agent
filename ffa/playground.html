API

import { createKernel } from "@focus-first/ffa";

const k = createKernel({ scale: 2, mode: "ffa" });        // 1 sim-minute = 2 s
k.ev.on("change", () => render(k.S));                      // S is the full state snapshot

const c = k.classify(task, "delete_file", { path: "db/old.sql" });   // → { kind: "ar", level: "caution", irreversible: true, ... }
const r = k.route(c);                                                 // { status: "act" | "pending" | "blocked" | "bypassed", id, promise }

k.human("commit");           // coarse breakpoint: pending Cautions are delivered now
k.human("away"); k.human("back"); k.human("focus");
k.answer(id, optionIndex);   // Warning option 0 needs a second press (returns "armed" first)
k.undo(id);                  // revert a decided-for-you default; the agent is told
k.takeResolved(agentId);     // decisions that resolved while the agent worked
k.hasOpen(agentId); await k.waitAny(agentId);
k.deliverEvidence(task, packet, archLevel, verified);
k.record(agentId, entry); k.recordFiles(agentId, files); k.recordSummary(agentId, packet);
k.stop();

行为

关注点行为
分类按效果而非工具名：fs.read / fs.write / fs.delete / net.out / proc.exec / message.out；scope 感知
级别Warning（consent，推送，阻塞）· Caution（consent，收件箱，延迟到断点）· Advisory（exception：applyAfter 后按安全默认，进"已替你决定"，可撤销）
人的状态FOCUS / BREAKPOINT / AWAY；Caution 等下一个断点，Warning 从不等
合并同 batch_key 5 分钟内合并为一行 digest
Flood同一 Agent 10 分钟 ≥ 10 条事件折叠为一条
超时Advisory → 默认 → decided[]；答过的项在超时前剔除
审批记忆人（或 bypass）批准过的同一效果，重试直接放行
证据verifier 失败或架构级变更 → Caution，永不自动合并
双计数base（逐条弹窗会花多少）与 ffa（实际到人的）；按状态单价 FOCUS 12、断点 1、离线推送 3
回看数据review.{transcript, files, summaries, silent, irreversible}：bypass 下人事后要读的东西
模式ffa（默认）或 bypass（无人被问，默认直接执行，静默决定与不可逆动作被记录）

测试
✔in-scope reversible write is ACT and lands in the digest, not the inbox
✔irreversible delete during FOCUS is a Caution that waits for a breakpoint
✔Warning is delivered immediately, blocks, and needs a second press
✔Advisory applies its default after applyAfter and appears in decided[]
✔an answered Advisory does not time out a second time
✔goal and taste questions are never Advisory, even with a recommendation
✔same batch_key merges into one digest line
✔ten events in ten minutes fold into a single flood item
✔non-allowlisted command is a Caution delivered now; allowlisted is ACT
✔approval memory: after a human approves an exact effect, the retry passes as ACT
✔bypass mode asks nobody, executes defaults, and records silent + irreversible
✔evidence: verifier failure or architecture-level change is a Caution with no auto-merge
✔undo of a decided-for-you default informs the agent
